# 🛒 Mini Shopping Cart

A Java-based shopping application developed as a college team project.
The application provides a shopping interface with user authentication,
product browsing, cart management, and checkout functionality.

---

## ✨ Features

- User login and registration
- Product browsing and selection
- Shopping cart management
- Checkout functionality
- Database connectivity
- Graphical user interface

> Note: Features depend on the current project implementation.

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Eclipse IDE or another compatible Java IDE
- MySQL Server (if required)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Asnasnap/Mini-Shopping-Cart.git
```

**2. Import the project into Eclipse**

- Open Eclipse IDE.
- Select **File → Import → Existing Projects into Workspace**.
- Select the cloned project folder.

**3. Configure and run**

- Configure the database connection if required.
- Run the application's main Java class.
