Mini Shopping Cart

Mini Shopping Cart is a Java-based shopping application developed as a college mini-project. It provides a simple shopping experience with user login and registration, product browsing, cart management, and checkout functionality. The application uses a database to manage user information and shopping-related data.

✨ Features
User login and registration
Product browsing and selection
Shopping cart management
Checkout functionality
Database connectivity
User-friendly graphical interface

🚀 Getting Started
Prerequisites
Java Development Kit (JDK)
Eclipse IDE or another compatible Java IDE
MySQL Server, if required by the application
Installation
Clone the repository:
git clone https://github.com/Asnasnap/Mini-Shopping-Cart.git
Open Eclipse IDE.
Select File → Import → Existing Projects into Workspace.
Select the cloned project folder.
Configure the database connection in DBConnection.java, if applicable.
Run the application's main Java class.
